Cas client : cinq sociétés, une plateforme

E-commerce B2B multi-sociétés pour DEMA Group

Équipement industriel : pompes, vannes, bandes transporteuses, irrigation

Une plateforme e-commerce unifiée pour cinq fournisseurs industriels dans un monorepo Turborepo. Chaque marque, DEMA, Fluxer, Beltz247, De Visschere et Accu, exploite sa propre vitrine Next.js sur une base PostgreSQL partagée, avec composants UI communs et authentification centralisée, connectée aux ERP Odoo et Exact Online.

  • Next.js 14
  • TypeScript
  • Prisma
  • PostgreSQL
  • tRPC
  • Turborepo
  • Stripe
  • NextAuth
  • Vercel
5marques sur une seule base de code
30+tables de base de données partagées
2ERP intégrés (Odoo, Exact Online)
