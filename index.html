Case: five companies, one platform

Multi-company B2B e-commerce for DEMA Group

Industrial equipment — pumps, valves, conveyor belts, irrigation

A unified e-commerce platform for five industrial supply companies in a Turborepo monorepo. Each brand — DEMA, Fluxer, Beltz247, De Visschere, Accu — runs its own Next.js storefront on a shared PostgreSQL database with shared UI components and centralized authentication, connected to Odoo and Exact Online ERP systems.

  • Next.js 14
  • TypeScript
  • Prisma
  • PostgreSQL
  • tRPC
  • Turborepo
  • Stripe
  • NextAuth
  • Vercel
5brands on one codebase
30+shared database tables
2ERP systems integrated (Odoo, Exact Online)
